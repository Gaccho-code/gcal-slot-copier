# GCal 空き時間コピー

クライアントとの日程調整を効率化するためのChrome拡張機能です。
Googleカレンダー(週表示)を開いた状態でツールバーのアイコンをクリックすると、
条件に合う空き時間を最大3件、コピー用の箇条書きテキストとして表示します。

```
・8/18(火) 10:00〜11:00
・8/19(水) 13:00〜14:30
・8/21(金) 9:00〜10:30
```

## 特徴

- Google Calendar APIやOAuth連携は使わず、**いま画面に表示されている週のGoogleカレンダーの画面(DOM)を解析**して空き時間を検出します。
- 空き枠の条件(営業時間・最低所要時間・平日のみ対象か)はオプション画面から変更できます(初期値: 平日9:00〜18:00・最低60分)。
- 生成したテキストは自動コピーされず、必ずポップアップ内でプレビューを確認してから「コピー」ボタンでクリップボードにコピーします。

## インストール(開発者モード)

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダ(`02_gcal-slot-copier`)を選択する

## 使い方

1. `https://calendar.google.com/` で予定を確認したい週を表示する(**週表示である必要があります**)
2. ツールバーの拡張機能アイコンをクリックする
3. ポップアップに空き時間の候補(最大3件)がプレビュー表示されるので、内容を確認する
4. 「コピー」ボタンを押すと、メールやチャットに貼り付けられるテキストとしてクリップボードにコピーされる

## オプション

ポップアップ下部の「オプションを開く」、または拡張機能を右クリック→「拡張機能のオプション」から以下を変更できます。

- 営業時間(開始・終了)
- 最低所要時間(分)
- 平日のみを対象にするかどうか

## 既知の制限

- 対象は**画面に表示中の週のみ**です。別の週を確認したい場合は、Googleカレンダー側で週を切り替えてから再度アイコンをクリックしてください。
- GoogleカレンダーのDOM構造は予告なく変更されることがあり、その場合は空き時間の検出に失敗する可能性があります。失敗時はポップアップにエラーメッセージが表示されます(詳細は [AGENTS.md](AGENTS.md) を参照)。
- アイコン画像は現時点でプレースホルダーの単色画像です。
