# GCal 空き時間コピー

クライアントとの日程調整を効率化するためのChrome拡張機能です。
Googleカレンダーの画面右下に常駐する小さなパネルから、空いている時間帯を好きなだけ集めて、
コピー用の箇条書きテキストとして取得できます。

```
・8/18(火) 10:00〜11:00
・8/19(水) 13:00〜14:30
・8/21(金) 9:00〜10:30
```

## 特徴

- Google Calendar APIやOAuth連携は使いません。
- カレンダーの自動スキャンではなく、**あなたが目で見て空いている時間をドラッグ選択する**ことで
  正確に時間帯を取り込みます(Googleカレンダー側の予定表示の変化に振り回されにくい設計です)。
- 件数の上限はなく、必要な分だけ集めてから一括でコピーできます。
- 自動検出がうまくいかない場合は、パネル内の「手動で追加」から日付・開始・終了を直接入力できます。

## インストール(開発者モード)

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダ(`02_gcal-slot-copier`)を選択する

## 使い方

1. `https://calendar.google.com/` を開く(パネルは自動的に画面右下に表示されます)
2. 空いていそうな時間帯をカレンダー上でドラッグして選択する(予定を新規作成するときと同じ操作)
3. パネルの「＋ 選択中の時間を追加」を押す
   - Googleが表示する予定作成ポップアップの文字情報(日付・時間帯)を読み取って一覧に追加します
   - うまく読み取れなかった場合はエラーメッセージが出るので、「手動で追加」から日付・開始・終了を入力してください
4. 必要な件数がそろったら「コピー」を押す → クリップボードに箇条書きテキストがコピーされます
5. 拡張機能アイコンをクリックすると、パネルの表示/最小化を切り替えられます

## 一覧の保持について

- 追加した一覧は `chrome.storage.local` に保存され、ページを再読み込みしても消えません
- 不要になったら個々の項目の「×」、または「クリア」で全削除できます

## 既知の制限

- 「選択中の時間を追加」は、Googleカレンダーが表示する予定作成ポップアップの文字列(日付・時間帯)を
  その場で1回だけ読み取る仕組みです。ポップアップの文言パターンによっては読み取れないことがあり、
  その場合は必ず「手動で追加」で入力できます(詳細は [AGENTS.md](AGENTS.md) を参照)。
- アイコン画像は現時点でプレースホルダーの単色画像です。
