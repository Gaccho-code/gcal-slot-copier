# 導入説明書 — 空き時間コピーくん

対象読者: これから Chrome にこの拡張機能を導入する方(開発者モードでの手動インストール)。

## 1. 事前準備

- Google Chrome(または Chromium 系ブラウザ)がインストールされていること
- この拡張機能一式のフォルダ(`02_gcal-slot-copier`)が手元にあること
  - GitHub から取得する場合は以下を実行します

```bash
git clone https://github.com/Gaccho-code/gcal-slot-copier.git
```

> ビルド作業は不要です。`npm install` などのコマンドを実行する必要はありません。

## 2. インストール手順

1. Chrome で `chrome://extensions` を開く
2. 画面右上の「デベロッパーモード」のトグルを ON にする
3. 「パッケージ化されていない拡張機能を読み込む」ボタンをクリックする
4. ファイル選択ダイアログで、取得した `02_gcal-slot-copier` フォルダ(`manifest.json` が直下にあるフォルダ)を選択する
5. 拡張機能一覧に「空き時間コピーくん」が追加されれば完了

### 確認方法

- `chrome://extensions` の一覧に「空き時間コピーくん」が表示され、有効(トグルON)になっていることを確認してください。
- エラーが表示された場合は、選択したフォルダが正しいか(`manifest.json` が直下にあるか)を確認してください。

## 3. 使い方

1. `https://calendar.google.com/` を開く
   - 画面右下にパネルが自動的に表示されます(初回はデフォルトで最小化された状態です)
2. 拡張機能アイコン、またはパネルのヘッダー部分をクリックしてパネルを展開する
3. カレンダー上で、空いていそうな時間帯をドラッグして選択する(予定を新規作成するときと同じ操作)
   - Google 標準の予定作成ポップアップが表示されます
4. パネルの「＋ 選択中の時間を追加」ボタンを押す
   - ポップアップの日付・時間帯のテキストを読み取り、一覧に追加されます
   - 読み取りに失敗した場合はエラーメッセージが表示されます。もう一度ドラッグ選択してから押し直してください
5. 必要な件数集まったら「コピー」ボタンを押す
   - 一覧が箇条書きテキストとしてクリップボードにコピーされます(同じ日の枠は自動的に1行にまとまります)
6. コピーしたテキストを、メールやチャットの本文に貼り付けて利用する

### パネルの操作

| 操作 | 内容 |
|---|---|
| 拡張機能アイコンをクリック | パネルの表示/最小化を切り替える |
| パネルのヘッダー部分をクリック | 同上(アイコンと同じ切り替え) |
| 各枠の「×」 | その枠だけを一覧から削除する |
| 「クリア」 | 一覧をすべて削除する |

- 一覧は `chrome.storage.local` に保存されるため、ページを再読み込みしても消えません。
- 不要になった枠は個別に削除、または「クリア」でまとめて削除できます。

## 4. アンインストール

1. `chrome://extensions` を開く
2. 「空き時間コピーくん」の「削除」ボタンをクリックする

## 5. 困ったときは

| 症状 | 対処 |
|---|---|
| 「選択中の時間帯が見つかりませんでした」と表示される | カレンダー上で改めてドラッグ選択し、予定作成ポップアップが表示されている状態で再度ボタンを押してください |
| コンソールに `Extension context invalidated` と表示される | 拡張機能を更新/再読み込みした直後に古いタブで発生する無害な現象です。該当のカレンダータブをリロードしてください |
| パネルが表示されない | 対象URLが `https://calendar.google.com/*` であるか、拡張機能が有効になっているか(`chrome://extensions`)を確認してください |
| コピーがうまくいかない | ブラウザのクリップボード権限がブロックされていないか確認してください。失敗時は自動でフォールバック処理が働きますが、改善しない場合はページを再読み込みしてください |

その他の制限事項・技術的な背景は [README.md](../README.md) と [要件定義書](requirements.md) を参照してください。
